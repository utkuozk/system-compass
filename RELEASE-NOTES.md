System Compass 1.8 — normal Windows installation

**Download System-Compass-Setup-1.8.0.exe.** Follow the Turkish/English wizard. The required runtime is bundled, so no ZIP extraction or separate .NET installation is needed. Setup creates desktop/Start menu shortcuts and registers normal uninstall in Windows Installed apps. Reports and settings are preserved. Close the app after maintenance completes before installing/removing. No automatic restart or maintenance scan is started. The installer is unsigned and requires 64-bit Windows 10/11. Automated compilation/tests do not replace interactive install/uninstall testing.

Previous improvements:

- Window dimensions fit the desktop work area. Native minimize, maximize/restore, close and resize controls remain enabled; the page heading can also be dragged or double-clicked.
- Redesigned update workspace with a compact toolbar, readable table, status badges and selected-item actions.
- Software inventory is independent from Windows/driver inventory. Windows and drivers share a queue; servicing and installations remain serialized.
- Official release feed defaults to utkuozk/system-compass.

The ZIP remains for older updater compatibility and advanced portable use only. Direct software updates support eligible MSIX packages only. Automated tests do not perform real system repairs or update installation.
